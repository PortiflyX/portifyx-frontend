# portifyx-frontend

Standalone Next.js 14/15 web application for PortifyX, featuring responsive multi-exchange portfolio tracking, balance masking, and exchange connection wizards.

## Tech Stack

- **Framework**: Next.js 15 (App Router, React Server Components + Client Islands)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS with Figma Dark Token Palette
- **State & Data Fetching**: TanStack Query (React Query v5), Zustand for client-side state
- **Icons**: Lucide React
- **Responsive Viewports**:
  - Mobile (375px) with fixed bottom navigation bar
  - Tablet (768px)
  - Desktop (1440px) with collapsible sidebar

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server on port 3000
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the dashboard.
